

学习到了四个ros2概念

package：组织代码、依赖和安装规则，例如 move_car_simulation；

executable：可以由 ros2 run 启动的程序，例如 talker；

Node：程序运行后出现在 ROS graph 中的节点；

launch 文件：启动和配置一个或多个程序的描述文件，本身不是某个 Node 的 executable。


ros2 node info /talker 显示了节点的发布者、订阅者、Service、Action 等接口。

Topic 消息类型需要查询 echo


发布者停止之后若没有其他节点使用该 Topic，发现信息更新后它通常会从 ros2 topic list 中消失。但其他发布者或订阅者仍在时，它可能继续出现；

launch 文件是不是可执行脚本：你的直觉抓到了一部分——它确实是 Python 文件，但“launch 文件就是 Node 的 executable”是错误的。
ros2 launch 会加载 launch 文件，launch 文件创建 Node、ExecuteProcess 等启动动作；它本身不是其中某个 ROS 节点的 executable。

/odom 就是里程计（Odometry）。
/cmd_vel 是 速度控制指令（Command Velocity）

__init__ 是 Python 里面最核心的一个概念，叫做“初始化方法”（或者叫构造函数）
QoS 全称是 Quality of Service（服务质量）。
你可以把它理解为：咱们俩通信，我该用什么态度对待数据？

Reliability（可靠性）
RELIABLE（可靠，默认值）：发消息就像寄顺丰快递。如果包裹丢了，必须重传，保证你 100% 收到。

BEST_EFFORT（尽力而为）：发消息就像听收音机。信号丢了就丢了，下一秒钟会有新的声音传过来，绝对不重传。

2. Durability（持久性）
VOLATILE（易失，默认值）：如果你晚一秒开始监听，之前发的消息你就收不到了。

TRANSIENT_LOCAL（持久）：就像微信群聊的“历史消息”。我晚进群，我也能看到群主之前发的置顶消息（比如地图数据、静态参数）。
