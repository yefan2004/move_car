# PC 环境检查

**日期** 2026-10-07  
**机器** 仿真用 PC，x86_64

## 结论

这台电脑已经可以开始阶段 1 的仿真工程。ROS 2 Humble、Nav2、SLAM Toolbox、RViz2、colcon 和 Gazebo Classic 11 都已安装，并且 ROS 2 已写入 `~/.bashrc`。

仿真器使用 **Gazebo Classic 11.10.2**，通过已安装的 `ros-humble-gazebo-ros-pkgs` 接入 ROS 2。Humble 的 `gazebo_ros` 就是对着 Classic 11 构建的。新 Gazebo（`gz sim` / Ignition Fortress）没有安装；当前的 `gz` 命令是 Classic 的辅助工具，不是新仿真器。本阶段不另装一套仿真器。

`robot_localization` 未安装。方案一第一版先用里程计，融合 IMU 留到实车标定之后再决定，现在不用补装。

## 当时执行的命令

```bash
lsb_release -a
printenv ROS_DISTRO
which ros2
ros2 --version
gazebo --version
ros2 pkg prefix nav2_bringup
ros2 pkg prefix slam_toolbox
nvidia-smi
```

`ros2 --version` 会报 `unrecognized arguments`，这是命令本身没有该参数，不代表 ROS 2 没装好。版本以 `ros-humble-desktop` 0.10.0 为准。
